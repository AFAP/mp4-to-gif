# MP4 → 透明 GIF / WebP 使用说明

> 本文件随 Release 一起发布，离线也能看。
> 程序下载：<https://github.com/AFAP/mp4-to-gif/releases/latest>

把视频（mp4）转成带透明背景的动图（GIF 或 WebP）。
单文件程序，不需要装 Python，也不需要单独装 ffmpeg（已内置）。

## 〇、怎么启动

双击 `mp4togif.exe` 就行。就这一个文件（约 74 MB），拷到哪里都能用。

> 为什么这么大？为了方便使用，程序把 ffmpeg（解压后约 87 MB）和 Python 运行时一起打包进了这一个 exe，
> 所以目标机器不需要装 Python、不需要装 ffmpeg，也不需要联网下载组件。

首次运行时，它会在自己旁边解压出一个「mp4togif_运行文件」文件夹，之后每次启动直接复用、不再重复解压（第二次起启动很快）。
那个文件夹是程序自己的运行文件，不用管它，**也别删**。

> 小提示：建议放在有写权限的位置（桌面、文档、U 盘都行）。
> 如果放在 `C:\Program Files` 这类只读位置，它会自动把运行文件放到用户目录 `%LOCALAPPDATA%\mp4togif` 下，也能用，只是每次启动多等几秒。

## 一、怎么用

1. 双击 `mp4togif.exe`
2. 点「选择 mp4 文件…」或「选择文件夹…」把要转的视频选进来（可多选 / 整个文件夹）
3. 选尺寸预设，或直接填宽 × 高
4. 填体积上限（微信表情填 `500`；不限体积填 `0`）
5. 选输出格式：
   - **GIF**：兼容性最好，但只有 1-bit 透明、256 色
   - **WebP**：支持真透明 + 全彩，同样体积下画质明显更好（推荐）
6. 点「开始转换」，日志区会实时显示进度和校验结果：
   - 绿色 `✓` = 成功
   - 红色 `✗` = 失败
   - 橙色 `!` = 需要注意（比如到了阶梯末端仍超限）
7. 输出默认放在每个视频自己所在目录下的 `gif\` 或 `webp\` 子目录；也可以在最下面指定统一目录

**界面说明**

- 「3 高级」默认收起，点「展开设置」才展开 —— 里面的参数一般不用动。
- 每一行右侧的灰色小字写的就是这一项的调法。
- 窗口大小按内容自动适配并居中，高分屏（150% 缩放）上也不会跑到屏幕外。
- 操作条右侧有**「打开输出目录」**：点一下用资源管理器打开成品所在目录。
  优先用「4 保存到」里指定的目录，其次是你最近一次转换实际写入的目录；
  两者都没有时，按「4 保存到」留空的规则推算（第一个视频同级的 `gif\` 或 `webp\`），
  目录还不存在会提示「转换完成后才会有」。

## 二、几个最重要的经验（工具已经内置，这里说明原理）

1. **抠白底只抠「与画面边框连通」的白色区域。**
   角色身上的白色部件（白身体、白云、白墙、白装甲）被轮廓或阴影包住，不与边框连通，所以不会被误抠掉。

2. **抠像在 768 像素长边做（超采样）**，掩膜降采样后再按 0.5 阈值硬化。
   GIF 只支持 1-bit 透明，这样做出来的边缘才是平滑的，否则会有锯齿。

3. **边缘色彩外推**：把透明区域的 RGB 换成最近的不透明像素颜色，
   避免缩放时把白底混进黑色描边、形成一圈白边。

4. **白色描边会被一起抠掉**（描边也是白的、和背景连通），
   所以工具会沿轮廓向外重建一圈纯白（默认 2 像素）。
   否则在深色聊天背景下，深色描边和文字会看不清。

5. **绝对不要加像素级模糊。** 模糊会把黑色描边糊成碎点，线稿直接毁掉。
   省体积要靠降帧率和降色数，不是靠模糊。

6. **颜色发闷不要靠加色数或降帧率解决** —— 用「调色板饱和」（默认 1.30）。
   它只把调色板里的颜色提饱和、像素索引不变，所以体积零增长。
   实测 1.30 最合适，1.5 开始偏橘。

7. **体积上限下，帧率和色数只能二选一。** 工具会从高帧率往下试，直到装进上限。
   「优先保帧率 / 保色彩」决定先牺牲哪一个。
   素材越短能负担的色数越高（3 秒能上 64 色，5 秒往往只能 24 色）。

8. **灰调素材（石头、白墙、灰砖）靠「提亮」而不是提饱和度。**
   而且提亮之后大片像素趋近纯白，文件反而会更小。
   这类素材把「亮度」填 1.08～1.18 试试。

9. **WebP 的同体积画质远好于 GIF**（大约 10 倍效率）。
   如果是给网页或 App 用，优先选 WebP。

## 三、参数怎么调

**尺寸预设**

- 微信表情 240×240
- 竖版头像 / 吉祥物常用 400×600（2:3）
- 网页用 240×360 能在 1MB 内做到 12fps + 64 色

**体积上限**

微信表情平台单张 500KB。工具留了余量，一般会压到 490KB 以内。
填 `0` = 不限体积，此时会用阶梯里最高的一档。

**优先保帧率 / 保色彩**

- 保帧率：先降色数（画面会平一点，但动作流畅）
- 保色彩：先降帧率（颜色和纹理更厚，但动作会顿）

**亮度 / 饱和度**

像素级调整，默认都是 1.00 不动。
偏暗的素材把亮度填 1.08～1.18；偏灰的素材也可以同时给饱和度 1.10～1.15。

**调色板饱和**

默认 1.30，体积零增长。想让颜色更艳就往上加，但超过 1.5 会偏橘。

**抠像阈值**

默认 244。视频生成模型的背景白会漂移（有的帧 250–255，有的 247–250），
244 是兼顾两边的值。如果发现背景没抠干净，可以调到 248；
如果发现角色浅色部分被吃掉了，调到 240。

**白描边宽度**

默认 2 像素。素材本身没有白色描边的，填 0。

**WebP 质量**

默认 80，一般不用动。

## 四、命令行模式（可选，方便批量或脚本调用）

```
mp4togif.exe --cli <文件或文件夹> [选项]
```

| 选项 | 说明 |
|---|---|
| `--out <目录>` | 输出目录（默认视频同级的 `gif\` 或 `webp\`） |
| `--size 240x240` | 输出尺寸 |
| `--limit 500` | 体积上限 KB（`0` = 不限） |
| `--fmt gif\|webp` | 输出格式 |
| `--prefer fps\|color` | 优先保帧率还是保色彩 |
| `--brightness 1.1` | 提亮 |
| `--saturation 1.1` | 提饱和度 |
| `--palette-sat 1.3` | 调色板饱和度（体积零增长） |
| `--threshold 244` | 抠像阈值 |
| `--keyline 2` | 白描边宽度 |
| `--webp-quality 80` | WebP 质量 |
| `--keep-bg` | 不抠底、保留原背景 |
| `--log <文件>` | 日志文件（默认输出目录下的 `_转换日志.txt`） |

例：

```powershell
mp4togif.exe --cli D:\videos --out D:\out --size 240x240 --limit 500 --brightness 1.1
```

- 命令行模式会在输出目录写一份 `_转换日志.txt`。
- 程序是 GUI 子系统（`--windowed`），`--cli` **不往控制台打印**，结果看日志文件。
- 退出码：`0` 全部成功，`1` 有失败，`2` 没找到视频文件 —— 方便脚本判错。

## 五、常见问题

**Q：转出来边缘有白边？**
A：是边缘色彩外推没起作用或描边宽度不够。把「白描边宽度」调到 2～3。
如果原视频本身背景不是纯白（比如带渐变），抠像会不准，需要先处理源视频。

**Q：角色身上的白色部分被抠没了？**
A：说明它和背景连通了（轮廓有缺口）。把「抠像阈值」调低到 240 或 238 试试。

**Q：背景没抠干净，留了一圈白？**
A：把「抠像阈值」调高到 246～248。

**Q：颜色太暗 / 太灰？**
A：提「亮度」，不要只提饱和度。灰调素材提饱和几乎没效果。

**Q：文件超 500KB？**
A：直接降低体积上限值，工具会自动降档。或者选「优先保色彩」让它先降帧率。

**Q：能动但很顿？**
A：帧率被压到 6fps 了。解决办法：把源视频剪短（3 秒能多拿一档帧率和色数），
或者放宽体积上限，或者选「优先保帧率」。

**Q：双击没反应 / 启动报错？**
A：看 exe 旁边的 `单文件启动日志.txt` 和 `%TEMP%\mp4togif_boot.log`，里面记了失败原因。

**Q：会联网上传我的视频吗？**
A：不会。全程本地 ffmpeg 抽帧 + 本地编码，程序里没有任何网络代码。

## 六、目录说明

Release 里下载到的文件：

```

mp4togif.exe.sha256   校验和（Get-FileHash -Algorithm SHA256 对一下）
usage.txt              本文件
```

首次运行后，exe 旁边会多出：

```
mp4togif_运行文件\     程序自己的运行文件，不要删
```
